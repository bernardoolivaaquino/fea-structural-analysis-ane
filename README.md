# FEA & Structural Analysis (ANE)

Structural and numerical analysis coursework developed at **UNAQ** (*Análisis Numérico / Estructural — ANE*).

## Overview
Combines analytical truss/structural solvers written in **Python** with **ANSYS** finite element simulations and APDL macros.

## Repository Structure
- **`python-analytical/`** — Python scripts (`solucion.py`, `tucola.py`, `una página.py`), truss calculation spreadsheets (`Calculo_Armadura_*.xlsx`), and coursework assignments (`Tarea 2`, `Tarea 3`, `practica 3`, `Práctica 4`, `Práctica 5`, `Tema4`).
- **`ansys-simulations/`** — ANSYS finite element models and practice cases (`E1`, `E2`, `P2`, `T2`, `TBBOA`, `ultimo`).

## Tools & Technologies
- **Python** (Analytical structural mechanics & truss calculations)
- **ANSYS Mechanical / APDL** (`.mac` macros and FEA setups)
- **Excel** (Verification and tabulated reaction/stress outputs)

> *Note: Heavy ANSYS solver result files (`.rst`, `.db`, `.emat`, `.esav`, `.full`) are excluded via `.gitignore`.*
